# Release 1.2 — deferred composition capabilities

Release 1.2 contains work deliberately excluded from the Release 1.1
implementation plan. These documents are discovery inputs, not approved
implementation plans:

- [01-floats-and-text-direction.md](01-floats-and-text-direction.md) separates
  float geometry, bidirectional text, shaping and CJK line breaking from the
  Release 1.1 composition cleanup;
- [02-visual-calibration.md](02-visual-calibration.md) defines the entry
  conditions for broader cross-brand visual calibration after the Release 1.1
  chrome and composition-quality mechanisms are stable.

Neither task belongs to the Release 1.1 acceptance gate.
